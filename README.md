# Kiprop Haggai — Personal Portfolio

A responsive, multi-view portfolio published through GitHub Pages. Built with semantic HTML, CSS and vanilla JavaScript; navigation uses hash routes so project detail pages work on static hosting.

## Pages
- Home — introduction, selected impact figures and featured case studies
- Experience — career timeline
- Projects — searchable and filterable case-study library
- About — professional profile, expertise, education and credentials
- Contact — email and public writing link

## Run locally
Open `index.html` in a browser or serve this folder with any static web server.

## Publishing
The repository name `kip-01.github.io` is configured as a GitHub user-site repository. With GitHub Pages serving the `main` branch root, the site is available at `https://kip-01.github.io`.

## Content integrity
Project figures are labelled as programme-level results or proposal-stage targets where appropriate. The JEEP and Healthy Nursery Children case studies are proposal/design records, not claims of completed delivery. The Kenya4Resilience and TerraOre role periods overlap in the source CV/site records; the Experience page flags this for confirmation.

## Assets
Selected WASH and school-environment photographs are sourced from the user's Google Drive archive and optimised as WebP for web delivery.
