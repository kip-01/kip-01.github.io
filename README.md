# Kiprop Haggai: personal website

A single-page, interactive personal site (plain HTML, CSS and JavaScript). No build step, no tracking.

## Publish free on GitHub Pages

1. Create a GitHub account on the **Free** plan if you don't have one.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username). Your site will then live at `https://YOUR-USERNAME.github.io`.
3. Upload `index.html` to the repository root (Add file > Upload files > Commit).
4. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, then Save.
5. Wait one to two minutes, then open your URL.

Notes:
- GitHub Free supports Pages on public repositories. GitHub Pro adds Pages for private repositories, which you do not need for a portfolio.
- Pages is for personal and project sites, not for running a business or taking payments. A portfolio is fine.
- Free limits: sites up to 1 GB, soft bandwidth of 100 GB per month. This site is under 50 KB.
- A custom domain (for example kiprophaggai.com) can be added later under Settings > Pages.

## Things to edit before you publish

- Contact: the site shows your email only. Your phone numbers and referees' details are left off on purpose because the page is public.
- K4RC dates: this site uses Jul 2020 to May 2024, as in your master CV. Your Haki Yetu CV says May 2025. Confirm which is right.
- Hero line "Open to project coordination and programme roles": change or remove it as you wish.
- To add a downloadable CV, put `cv.pdf` next to `index.html` and add a link such as `<a class="btn line" href="cv.pdf">Download CV</a>`.
